## Le défi quotidien sur Discord

Chaque jour, à l'heure configurée, Kotbo publie un message structuré dans le salon dédié aux défis :
* **L'énoncé** : Description et consignes du problème algorithmique à résoudre.
* **La difficulté** : Indication du niveau (Facile, Moyen, Difficile).
* **Les langages acceptés** : Liste des syntaxes de programmation autorisées pour ce défi (ex: `Python`, `JavaScript`, `TypeScript`).
* **La signature de fonction** : Le nom de la fonction attendue et ses arguments typés.

---

## Comment soumettre sa solution

Les participants ont deux méthodes pour soumettre leur code :

### Méthode 1 : Via l'application Discord
Les membres peuvent utiliser la commande slash de soumission du bot pour coller leur code source :
* Le bot ouvre une fenêtre de formulaire (modal) permettant de copier-coller son code de solution.
* Kotbo exécute immédiatement le code de manière sécurisée dans son bac à sable (sandbox) et fait tourner la batterie de tests unitaires définis par le staff.
* Le bot répond instantanément en privé pour indiquer si le code a passé les tests ou s'il comporte des erreurs d'exécution.

### Méthode 2 : Depuis son éditeur local (VS Code / API)
Pour les défis plus complexes, les développeurs peuvent lier leur environnement de travail :
1. Récupérez votre **Clé API Kotbo** personnelle depuis l'onglet dédié du dashboard.
2. Utilisez l'extension d'IDE compatible (comme VS Code) ou un script pour charger le sujet du jour en local.
3. Codez dans votre éditeur favori.
4. Lancez la commande de soumission API pour envoyer votre fichier directement à Kotbo pour correction.

## Langages de programmation supportés

L'exécuteur de code sécurisé de Kotbo est capable de compiler et d'exécuter des scripts écrits dans les langages suivants :
*   **JavaScript** (Runtime Node.js)
*   **TypeScript** (compilé puis exécuté)
*   **Python**
*   **C**
*   **Lua**
*   **SQLite** (requêtes sur base de données de test)
