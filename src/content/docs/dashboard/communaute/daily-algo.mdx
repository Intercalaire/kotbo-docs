<p class="doc-lead">Le module <strong>Daily Algo</strong> est une extension unique pour les communautés de développeurs, d’étudiants ou de passionnés de programmation. Il permet de publier chaque jour un défi algorithmique à résoudre directement sur Discord ou depuis le dashboard.</p>

:::tip[Côté Discord]
Pour comprendre comment les membres participent aux défis sur Discord et soumettent leur code, consultez le [Guide d'utilisation de Daily Algo](/discord/communaute/daily-algo).
:::

:::note[Disponibilité]
La gestion du module s'effectue dans l'onglet **Modération → Daily Algo** de votre dashboard : [Accéder au Daily Algo ↗](https://dash.kotbo.fr/dailyalgo).
Les langages supportés par l'exécuteur de code sécurisé de Kotbo sont : `JavaScript`, `TypeScript`, `Python`, `C`, `Lua`, et `SQLite`.
:::

## Les quatre onglets de la page

L'interface de Daily Algo s'organise autour de quatre onglets. Les deux derniers sont **réservés aux administrateurs** : un membre du staff qui n'a pas ce droit voit le message *Vous n'avez pas la permission de configurer ce module*.

### 1. Défis & Notation

L'onglet d'accueil du module. Trois indicateurs le résument en haut de page :
* **Soumissions du jour** : le nombre de solutions reçues aujourd'hui.
* **Bibliothèque** : le nombre d'exercices disponibles.
* **Planning** : le nombre de jours déjà programmés.

Le bloc **Défi en cours** affiche l'exercice du jour. S'il n'y en a pas, Kotbo indique *Aucun défi actif* et invite à *Planifier un défi pour commencer*. Le bouton **Changer le défi** remplace l'exercice du jour.

La table **Soumissions Récentes** liste les solutions envoyées, avec les colonnes **Statut**, **Auteur**, **Date** et **Actions**. Les filtres rapides affichent **Tout**, **En attente**, **Validés** ou **Rejetés**.

Ouvrez une soumission pour la relire dans l'éditeur de code intégré, consulter le résultat des tests et la noter.

### 2. Semaine & Podium

Le classement hebdomadaire, séparé en **Semaine en cours** et **Semaines clôturées**.

Le tableau donne, pour chaque **Membre**, ses **Points**, ses **Défis validés** et ses **Bonus manuels**, ainsi que le nombre de participants de la semaine.

:::note[Comment le classement se remplit]
Le classement évolue à mesure que le staff note les soumissions. Toute participation validée rapporte au moins le plancher de points prévu par le barème.
:::

Sans semaine ouverte, l'onglet affiche *Aucune semaine ouverte pour le moment*. Une semaine sans activité affiche *Aucune participation cette semaine*.

### 3. Barème & récompenses

:::caution[Réservé aux administrateurs]
Seuls les administrateurs peuvent modifier le barème. Les autres membres du staff voient le message *Vous n'avez pas la permission de configurer le barème de ce module*.
:::

* **Barème & points** : le nombre de points attribués selon la difficulté et la notation.
* **Activer les récompenses hebdomadaires** : verse automatiquement les récompenses à la clôture de la semaine.
* **Salon d'annonce** : le salon dans lequel Kotbo publie le podium de fin de semaine.
* **Points de clan** : activez **Convertir les points en points de clan**, puis réglez le **Taux de conversion** et les **Bonus clan** des trois premières places.

:::tip[Calibrer le taux de conversion]
Un taux de 1 signifie qu'un point Daily Algo vaut un point de clan. Un participant assidu pèse alors environ 70 points de clan par semaine, soit un peu plus qu'un passage de niveau.
:::

La section des points de clan n'est exploitable que si le module Clans est activé sur votre serveur.

### 4. Administration

:::caution[Réservé aux administrateurs]
Cet onglet n'est utilisable que par les administrateurs du serveur.
:::

* **Clôturer la semaine** : déclenche immédiatement ce que fait le cron du lundi. Le classement est figé, les récompenses versées, les rôles du podium attribués et l'annonce publiée. Une fenêtre de confirmation récapitule le nombre de participants et l'état des récompenses.
* **Rattraper les points de la semaine** : relance le calcul des points manquants sur la semaine en cours.

:::danger[La clôture ne s'annule pas]
Clôturer une semaine est irréversible. L'action sert surtout à tester le cycle complet sans attendre sept jours.
:::

## Langages autorisés et clés API

Les **langages autorisés** ne se règlent pas sur cette page, mais dans les réglages du module. Laissé vide, le champ autorise tous les langages ; vous pouvez aussi y ajouter des langages absents de l'IDE intégré. Chaque exercice peut ensuite imposer un langage précis ou laisser le choix libre.

C'est au même endroit que vos membres génèrent leur **clé API** personnelle, qui n'est affichée qu'une seule fois à la création. Elle leur permet de récupérer le sujet du jour et de soumettre leur code depuis leur éditeur local.
