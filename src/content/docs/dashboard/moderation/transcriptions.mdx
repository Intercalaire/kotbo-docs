<p class="doc-lead">Une <strong>transcription</strong> est une copie lisible du contenu d'un salon, générée par Kotbo au moment de sa fermeture. C'est ce qui reste d'un ticket de support une fois le salon supprimé.</p>

:::note[Où la trouver]
Section **Modération → Transcriptions** : [Ouvrir les transcriptions ↗](https://dash.kotbo.fr/transcripts-list).
La page appartient au module **Tickets support** : elle disparaît si ce module est désactivé.
:::

---

## D'où viennent les transcriptions

Kotbo génère une transcription dans deux situations :

* à la **suppression d'un salon de ticket**, dans le module [Tickets de support](/dashboard/communaute/tickets/). La transcription est alors obligatoire : elle est produite avant que le salon ne disparaisse, et son lien est publié dans le salon de logs. Fermer un ticket, en revanche, n'en génère aucune, puisque le salon existe toujours ;
* à la **demande d'un modérateur**, quand il importe des messages Discord comme preuves dans un [rapport de sanction](/dashboard/moderation/sanctions/). Une transcription distincte est alors créée pour chaque salon retenu.

---

## Consulter

* Le compteur en tête de page indique le nombre de transcriptions conservées.
* Le champ de recherche filtre par **nom de salon**.
* Le bouton **Ouvrir** affiche la transcription complète : messages, auteurs, horodatages et pièces jointes.
* **Charger plus** récupère les entrées suivantes.

Si la liste est vide, Kotbo indique soit *Aucun résultat pour cette recherche*, soit *Les transcriptions générées apparaîtront ici*.

---

## Supprimer

L'icône de suppression demande une confirmation directement sur la ligne (**Confirmer ?**) avant d'effacer la transcription.

:::danger[Suppression définitive]
Une transcription supprimée n'est pas récupérable. Si elle sert de preuve dans un rapport de sanction, le rapport perd sa pièce jointe.
:::
