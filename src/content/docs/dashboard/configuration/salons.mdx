<p class="doc-lead">Le module <strong>Salons</strong> regroupe toutes les fonctionnalités d'automatisation, de statistiques vocales et de sécurité liées aux salons de votre serveur Discord.</p>

:::tip[Côté Discord]
Pour voir le fonctionnement de l'Auto-Thread, des salons de statistiques, de la création de salon temporaire avec l'embed de contrôle et du piège Honeypot, consultez le [Guide Discord de gestion des salons](/discord/configuration/salons).
:::

:::note[Disponibilité]
Ce module est accessible depuis la section **Configuration → Salons** de votre dashboard : [Accéder au module Salons ↗](https://dash.kotbo.fr/channels-management).
:::

L'interface est structurée autour de quatre onglets principaux, détaillés ci-dessous.

---

## 1. Auto-Thread (Fils automatiques)

L'onglet **Auto-Thread** permet de définir des salons textuels ou d'annonces dans lesquels Kotbo créera systématiquement et automatiquement un fil de discussion (thread) pour chaque nouveau message posté.

### Configuration
* **Sélection des salons** : Cliquez sur les salons de la liste pour les activer ou les désactiver. Les salons sélectionnés apparaissent avec une bordure colorée et une coche.
* **Actions rapides** :
  * **Sélectionner tout (filtre)** : Sélectionne tous les salons actuellement visibles (utile si vous avez filtré par recherche).
  * **Tout désélectionner** : Décoche tous les salons configurés.
  * **Barre de recherche** : Filtre la liste des salons par nom pour retrouver rapidement un canal spécifique.

---

## 2. Salons Stats (Compteurs en temps réel)

Le sous-module **Salons Stats** permet d'afficher en temps réel des indicateurs clés de votre serveur (nombre de membres, d'actifs, de boosts, etc.) directement dans le nom de salons vocaux dédiés.

### Configuration globale
* **Activer le module** : Utilisez l'interrupteur principal en haut à droite.
* **Catégorie de création** : Sélectionnez la catégorie Discord où seront placés vos salons de statistiques.
  * *Option automatique* : Si vous laissez la sélection vide ou cliquez sur **Créer la catégorie**, Kotbo créera automatiquement une catégorie dédiée sur votre serveur Discord.

### Statistiques historiques
:::warning[Reconstruction des statistiques]
Kotbo dispose d'un outil pour analyser l'historique complet des messages de vos salons textuels afin de générer les graphiques d'activité sur le dashboard.
* **Lancer le Scan** : Parcourt l'historique en arrière-plan sans affecter les données déjà enregistrées.
* **Forcer le Re-scan** : Supprime et recalcule toutes les statistiques existantes du serveur. **Cette action est destructrice pour l'historique actuel du dashboard.**
:::

### Compteurs par défaut
Vous pouvez activer et personnaliser individuellement les compteurs suivants :
1. **Compteur de Membres** : Nombre total d'utilisateurs sur le serveur.
2. **Compteur de Bots** : Nombre total d'applications/bots.
3. **Compteur par Rôle** : Nombre de membres possédant un rôle cible spécifique (ex: `@Staff`).
4. **Compteur de Salons** : Nombre de salons textuels et vocaux présents.
5. **Compteur de Catégories** : Nombre total de catégories de salons.
6. **Compteur d'Activité (24h)** : Nombre de membres ayant envoyé un message ou rejoint un salon vocal au cours des dernières 24 heures.

Pour chaque compteur actif, vous pouvez spécifier un **salon vocal existant** ou laisser le bot le **créer automatiquement**, et personnaliser le modèle du nom (ex: `👤 Membres : {count}`).

### Compteurs personnalisés
En cliquant sur **Ajouter un compteur personnalisé**, vous pouvez configurer des compteurs additionnels en choisissant :
* **Type de statistique** : Membres totaux, Bots, Membres en ligne, Membres en vocal, Rôle spécifique, Salons totaux, Catégories, Actifs (24h), Boosts de serveur, ou Objectif de membres.
* **Objectif (Cible)** : Spécifique au type *Objectif de membres*, permet d'afficher la progression vers un but (ex: `🎯 Objectif : {count}/{goal}`).
* **Modèle du nom** : Utilisez la balise `{count}` (et `{goal}` pour les objectifs) qui sera remplacée dynamiquement par la valeur réelle.

:::note[Mise à jour des noms]
Pour respecter les limites de requêtes imposées par l'API Discord (Rate Limits), le bot rafraîchit le nom des salons de statistiques **toutes les 10 minutes**. Le changement n'est donc pas instantané sur Discord.
:::

## 3. Créer son salon (Salons temporaires)

Ce module permet aux utilisateurs de créer leur propre salon vocal temporaire et de le configurer de façon autonome à l'aide de boutons interactifs.

### Configuration du générateur
* **Salon Vocal Générateur** : Le salon vocal "d'appel". Dès qu'un membre rejoint ce salon, Kotbo l'en extrait, crée un nouveau salon temporaire et l'y déplace.
* **Catégorie de création** : La catégorie Discord dans laquelle les salons temporaires seront créés.
* **Modèle de nom du salon** : Le format du nom généré. Utilisez la balise `{user}` pour insérer le pseudonyme du créateur (ex: `🔊 Salon de {user}`).
* **Rôle requis** : Restreint la possibilité de créer des salons temporaires aux seuls possesseurs d'un rôle spécifique (laisser vide pour ouvrir à tous).
* **Générateurs additionnels** : Vous pouvez configurer plusieurs générateurs indépendants (chacun avec son salon déclencheur, sa catégorie cible, son modèle de nom et son rôle requis).

### Supervision depuis le Dashboard
En bas de l'onglet, la section **Salons Temporaires Actifs** liste tous les salons actuellement ouverts sur le serveur. Les administrateurs peuvent :
* Visualiser le nom du salon, son créateur actuel et le nombre de membres connectés.
* Modifier à la volée la réservation (Rôle requis).
* Renommer directement le salon en cliquant sur l'icône d'édition.
* Fermer et supprimer instantanément le salon en cliquant sur **Fermer**.

## 4. Salon Honeypot (Piège Anti-Spam)

Le **Salon Honeypot** est un outil de sécurité radical conçu pour détecter et neutraliser instantanément les bots de spam ou les comptes d'utilisateurs piratés (self-bots) qui rejoignent votre serveur.

### Configuration du piège
* **Salon Piège (Honeypot)** : Sélectionnez le salon à utiliser ou cliquez sur **Créer automatiquement**. Le bot créera un salon avec les permissions adaptées et y enverra un message embed d'avertissement.
* **Sanction à appliquer** :
  * **Exclusion Temporaire (Timeout)** *(recommandé)* : Applique une exclusion d'écriture de 28 jours sur Discord.
  * **Bannissement Définitif** : Bannit définitivement le compte du serveur et supprime ses messages des dernières 24 heures.
  * **Softban** : Bannit le membre puis le débannit immédiatement, ce qui a pour effet de purger tous ses messages récents sur le serveur.
  * **Exclusion Simple (Kick)** : Exclut le membre du serveur.
  * **Avertissement Simple (Warn)** : Enregistre un avertissement dans le dossier disciplinaire du membre.
* **Réinvitation automatique (Optionnel - Kick uniquement)** : Si activé, Kotbo enverra un DM à l'utilisateur exclu contenant un lien d'invitation unique valable 24h.
* Cliquez sur **Enregistrer** dans la barre inférieure verte après chaque modification.

:::caution[Avertissement de Sécurité]
Le Honeypot est une mesure de sécurité stricte. Veillez à ce que le nom du salon piège ou sa description soient explicites pour éviter que des membres légitimes ne se fassent sanctionner par curiosité ou inattention.
:::
